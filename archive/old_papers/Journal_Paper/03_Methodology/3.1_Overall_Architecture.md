# 3. Methodology

## 3.1 Overall Architecture

The proposed framework retains the dual-stream encoder–decoder organization of MAFF-Net and runs as a single forward pass, as shown in Fig. 1. A dermoscopic image first enters a frozen SAM2 (Hiera) image encoder, which produces feature maps at four spatial scales. Each scale is adapted by a Mixed Multi-scale Perception Adaptor that tailors the general-purpose encoder features to the dermoscopic domain while leaving the encoder weights unchanged. The adapted features are then enriched by the Frequency-Guided Feature Fusion module, which combines the spatial representation with frequency-domain information so that edge content weakened during encoding is reintroduced before decoding. The fused multi-scale features pass to a decoder that emits a segmentation prediction at every scale under deep supervision, and the highest-resolution prediction is taken as the final lesion mask. A separate reconstruction decoder operates alongside the segmentation decoder during training only; it reconstructs the input from the encoder features and is removed at inference, so it adds nothing to the deployed model.

This organization is inherited directly from the original MAFF-Net. In its published form, the framework freezes a SAM image encoder, adapts it with the perception adaptor, fuses spatial and spectral features, and regularizes the encoder representation through the auxiliary reconstruction branch. Supervision in that design comes from region-overlap losses on the segmentation predictions together with a reconstruction term on the auxiliary branch. The lesion boundary is consequently shaped only in an indirect way, through accurate interior prediction and faithful global reconstruction rather than through any signal that targets the margin itself.

Because a reference implementation suitable for controlled extension was not available to us, we first rebuild this design as a faithful base. The restored model reproduces the four original components, namely the frozen SAM2 encoder, the perception adaptor, the frequency-guided fusion module, and the reconstruction decoder, and it resolves the practical obstacles to stable training, the most important of which is computing the Fourier transform in single precision within an otherwise mixed-precision pipeline. The restored model matches the original architecture and serves as our experimental base throughout the study. It is the starting point for the proposed method and not part of the contribution, and we keep this separation explicit so that any measured effect can be attributed to the supervision we add rather than to a change in the network.

Our contribution, Boundary-centric Dual Supervision, is introduced on top of this base and changes only how the existing outputs are supervised. It adds no modules, no parameters, and no inference-time computation; the network that runs at test time is identical to the restored base. The supervision is applied at two points that the architecture already provides, summarized here and described in detail in the following subsections.

The first point is the set of multi-scale segmentation predictions produced by the decoder. Boundary-aware Deep Supervision attaches an additional, boundary-focused training signal to these predictions, so that each scale is encouraged to agree with the true lesion margin and not only with the lesion interior. Because the decoder already generates these predictions for deep supervision, the signal is added without any structural change.

The second point is the auxiliary reconstruction branch. Edge-weighted Reconstruction redirects the reconstruction objective so that it emphasizes regions near the lesion boundary instead of treating all pixels equally, turning a branch that originally enforced a generic appearance constraint toward the preservation of margin detail. Both signals are derived from the same boundary information and applied to two different parts of the network, the segmentation outputs and the reconstruction output, so the framework supervises the lesion boundary from two complementary directions within a single training process. At inference the reconstruction branch is discarded and only the segmentation decoder remains, and therefore the added supervision improves training without affecting the size or speed of the deployed model.
