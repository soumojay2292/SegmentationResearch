## 3.2 Mixed Multi-scale Perception Adaptor (MMPA)

The Mixed Multi-scale Perception Adaptor is a component of the original MAFF-Net, and the restored base reproduces it faithfully; nothing in this subsection forms part of the proposed contribution. Its purpose is to adapt the frozen SAM2 encoder features to the dermoscopic domain at low cost. The encoder is pretrained on natural images and kept frozen, so its features are general but not specialized for skin lesions. Instead of fine-tuning the large encoder, the MMPA places a small trainable adaptor at each of the four encoder scales that re-weights and re-shapes the features for the target task while the encoder itself remains fixed. As illustrated in Fig. 2, one adaptor is applied per scale, so adaptation takes place across the full feature hierarchy.

Within a single adaptor, the incoming feature map is first normalized and projected from its native channel width into a much smaller bottleneck space. This compression keeps the adaptor lightweight and forces it to retain only the information relevant to adaptation. The compressed representation is then processed in parallel by three convolutional paths that share the same form but differ in their dilation, so that each path covers a different receptive field. A separate weight generator inspects the global content of the compressed feature, through pooling followed by a small fully connected stage, and produces one normalized weight for each path. The three path outputs are combined according to these weights, the result is added back to the compressed feature through a residual connection, and the feature is then projected to the original channel width and added to the input. The adaptor therefore returns a feature of the same shape it received, which allows it to be inserted at every scale without altering the surrounding architecture.

The intuition behind the design is that different lesion structures are best captured at different spatial extents, and that the appropriate extent varies from one image to another. The three dilated paths realize progressively larger receptive fields, so that one path responds to fine local structure such as hair and texture, another to mid-range regions such as pigment clusters, and the third to the broader and often irregular shape of the lesion as a whole. The weight generator converts this into a content-dependent choice: rather than fixing how much each scale contributes, the network predicts the mixing weights from the input itself through a softmax, so the same adaptor can favour fine detail on one image and global shape on another. The residual connections are deliberately conservative. The combined multi-path response is scaled by a factor initialized to a very small value before it is added back, so that at the start of training the adaptor behaves almost as an identity mapping and departs from the frozen encoder's representation only gradually. This protects the strong pretrained features from being disrupted early in training and keeps the adaptation stable.

Within MAFF-Net, the MMPA occupies the stage between the frozen encoder and the frequency-guided fusion module. It is the mechanism through which the pretrained, domain-general encoder is reconciled with the requirements of dermoscopic segmentation, supplying scale-adapted features for the subsequent spatial–spectral fusion and decoding while adding only a small number of trainable parameters relative to the encoder. In the restored base used in this work, the adaptor reproduces this original behaviour, and the contribution introduced in the later subsections leaves it unchanged.
