1. IMPLEMENTATION USED
--------------------------------------------------------------------------------
No boundary-metric code existed in the repository before this step (verified by a
repo-wide grep for hd95/hausdorff/assd/surface_distance/boundary_iou, excluding
src/sam2). Established libraries were used rather than any hand-rolled approximation:

  HD95, ASSD : medpy.metric.binary.hd95 and .assd  (MedPy 0.5.2, installed for this
               evaluation; pulls SimpleITK 2.5.5). MedPy is the standard reference
               implementation of surface distances in medical image analysis.
  Boundary   : official formulation of Cheng et al., "Boundary IoU: Improving
  IoU          Object-Centric Image Segmentation Evaluation", CVPR 2021 —
               IoU restricted to a boundary band of width d = round(0.02 * diag),
               the band obtained by subtracting the morphologically eroded mask from
               the mask. Dilation ratio 0.02 is the paper's default.

  NEW CODE IS EVALUATION-ONLY and lives entirely in a scratch script; nothing was
  added to models/, modules/, training/, or train.py. The training code is untouched.

Prediction path is identical to the existing region evaluation:
  train.SegDataset(split="test", img_size=384), batch_size 2, torch.sigmoid,
  threshold 0.5. Each model is built exactly as train.py builds it (MAFF-Net family
  with the SAM2.1 Hiera-Large checkpoint; the Paper-faithful Reconstruction via the
  same _MAFFNetOriginalAdapter and placeholder encoder used in Step 2). For the
  deep-supervision models the primary head p1 (out[0]) is used, matching evaluation.


2. METRIC DEFINITIONS AND UNITS
--------------------------------------------------------------------------------
  HD95 : 95th-percentile symmetric Hausdorff distance between predicted and
         reference lesion contours. Error measure, LOWER is better.
  ASSD : average symmetric surface distance. Error measure, LOWER is better.
  Boundary IoU : intersection-over-union computed only within the boundary band.
         Overlap measure in [0,1], HIGHER is better.

  UNITS: pixels on the 384x384 evaluation grid. The ISIC images are resized from
  heterogeneous native resolutions and no physical voxel spacing is stored, so unit
  spacing is used; HD95/ASSD are NOT in millimetres and must not be compared with
  mm-denominated distances from other papers. They are fully comparable across the
  models in this table, which share one grid and one protocol.

  DEGENERATE CASES: HD95/ASSD are undefined if either mask is empty. Images with an
  empty PREDICTION are excluded from the distance means and reported as n_valid < n
  and in an "empty pred" column; no ground-truth mask in any split was empty (empty
  GT = 0 everywhere). Boundary IoU is defined for empty predictions (it evaluates to
  0 overlap) and uses all n images. This exclusion is disclosed, not hidden — a model
  that leaves lesions entirely unsegmented is penalised in Dice and in n_valid, and
  the count is printed per row.

7. SCIENTIFIC READING (recorded; the manuscript author decides how to use it)
--------------------------------------------------------------------------------
  a) The boundary metrics SUPPORT the paper's central thesis for the first time. On
     every dataset all three MAFF-Net variants beat all four baselines on HD95, ASSD
     and Boundary IoU by a wide margin (e.g. ISIC 2018 HD95: best baseline TransUNet
     41.8 px vs Restored 20.6 px, a ~51% reduction). The boundary-aware family is
     boundary-superior under boundary metrics, which is exactly the claim that was
     previously unmeasured.
  b) The Proposed-vs-Restored question from audit 18/19 PERSISTS and, if anything,
     sharpens. Restored has the lower HD95 and ASSD on all three datasets; Proposed
     wins Boundary IoU only on ISIC 2017 (0.5277 vs 0.5255) and is essentially tied
     on ISIC 2016 (0.4514 vs 0.4518). So boundary metrics do NOT rescue a "Proposed
     is best" claim — they reinforce that Restored is the stronger model overall. The
     positioning decision flagged in audit 19 (N1) is still required and is unchanged.
  c) These are single-run, unseeded results (same caveat as every other number in the
     project); no significance is claimed. The Proposed/Restored gaps here are small
     relative to the per-image std (e.g. HD95 std ~21-30 px), so they should not be
     described as meaningful differences without multi-seed variance.
  d) TransUNet is the strongest baseline on boundary metrics, consistent with its
     strong region performance; U-Net is the weakest, with the most empty predictions.
