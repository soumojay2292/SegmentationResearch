1. EXACT CODE CHANGES
--------------------------------------------------------------------------------
NEW FILE (canonical models untouched): models/stabilized_maffnet_ablation.py
  class StabilizedMAFFNetAblation(StabilizedMAFFNet): subclass that, after the
  parent __init__, swaps exactly ONE submodule group for a shape-preserving stand-in:
     ablate="freq"   : self.freq   = ModuleList([nn.Identity]*n)
                       -> frequency stream becomes align_f[i](f) (no high-pass)
     ablate="align"  : self.align_s = self.align_f = ModuleList([nn.Identity]*n)
                       -> fs=f, ff=freq[i](f) reach the gate unnormalised (c->c, safe)
     ablate="fusion" : self.fuse   = ModuleList([MeanFusion]*n)
                       -> learned gate replaced by fixed 0.5*(Fs+Ff)
  MeanFusion is a 3-line parameter-free nn.Module matching GatedFusion's signature,
  so the parent forward runs unchanged. The frozen SAM2 encoder, skip projections,
  decoder, heads, and RDB are inherited verbatim. Output stays a 5-tuple, so the
  canonical MAFFNetTrainer / MAFFNetLoss are used with no modification.

  Smoke-verified before any GPU time: all three variants build, forward on a
  384x384 input, return (p1,p2,p3,p4,rec) with p1=(1,1,384,384). Trainable-param
  counts: Full 11.0065M; -freq 11.0065M (FrequencyBranch is parameter-free, so the
  ablation isolates the spectral OPERATION, not capacity); -align 10.4802M;
  -fusion 10.4812M (each drops the removed 1x1 convs).

  NO EDIT was made to models/stabilized_maffnet.py, models/maffnet.py,
  training/trainer.py, or train.py (mtimes unchanged, verified post-run).

  READING (stated honestly):
  a) On REGION metrics the three modules are essentially NEUTRAL. Removing the
     Frequency Branch or the Gated Fusion actually leaves Dice marginally HIGHER
     (+0.0007, +0.0024); only Feature Alignment shows a positive region-Dice
     contribution (+0.0052). No module "improves Dice" in any meaningful sense.
  b) On BOUNDARY metrics all three modules contribute POSITIVELY on every measure:
     removing any one worsens HD95, ASSD and Boundary IoU. The Full Proposed model
     is the single best configuration on all three boundary metrics. This is exactly
     what the boundary-centric design predicts — the modules act on boundary fidelity,
     which region overlap barely reflects. This is the ablation's central result and
     it SUPPORTS the module-level framing of III-D/E/F.
  c) Relative importance is metric-dependent and should not be overstated:
     Feature Alignment is the most consistent contributor (top on ASSD and Boundary
     IoU, and the only one that also helps region Dice); Gated Fusion dominates HD95
     (the worst-case boundary error) but contributes least to ASSD/Boundary IoU;
     the Frequency Branch is a uniform, mid-sized positive on every boundary metric.

  CAVEAT (must accompany any use of this table): these are SINGLE, UNSEEDED runs.
  The boundary deltas (HD95 ~+1 to +3 px) are small against the per-image HD95 std
  (~26-30 px on this dataset). No statistical significance is claimed or implied.
  A multi-seed repeat (>=3) would be required before any delta is described as
  significant. The region-metric neutrality also means the paper must NOT claim the
  modules improve Dice; the defensible claim is that they improve boundary fidelity.
