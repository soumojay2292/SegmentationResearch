2. TRAINING PIPELINE
--------------------------------------------------------------------------------
Dataloaders (train.py:179-195): SegDataset -> torch DataLoader; shuffle=True for
   train, False for val/test; num_workers = --workers (default 2); pin_memory=True.
Augmentation (train split ONLY, SegDataset._augment, train.py:65-85):
   - Random horizontal flip (p=0.5), vertical flip (p=0.5).
   - Rotation, angle ~U(-30,30) deg (bilinear image / nearest mask).
   - Random affine (p=0.5): degrees +-15, translate 0.1, scale 0.9-1.1, shear +-5.
   - ColorJitter(0.2,0.2,0.2,0.1).
   - NO augmentation on val/test (only train split augments; train.py:103-104).
Batch size : --batch_size (default 2); recorded per run in config.txt
             (e.g. stabilized_maffnet_ISIC2016 = 2). Paper-faithful runs used 8
             (PUBLICATION_ENGINEERING_REFERENCE §6). Per-run value is authoritative.
Epochs     : --epochs (default 5; --fast=3); final experiments = 40 (config.txt).
Optimizer / scheduler / precision — TWO training paths:
   (a) MAFF-Net family (maffnet, stabilized_maffnet, maffnet_original_reconstructed)
       -> MAFFNetTrainer (train.py:238-266):
         * AdamW, lr default 1e-3, weight_decay 0.01 (trainer.py:280); MMPA gamma
           excluded from weight decay (trainer.py:275-284).
         * Scheduler LinearLR start_factor 1.0 -> end_factor 0.0 over num_epochs
           (trainer.py:287-291).
         * bf16 autocast, no GradScaler (trainer.py:337); non-finite loss guard
           raises (trainer.py:341); gradient-norm clip 1.0 (trainer.py:346).
         * NO early stopping (runs all epochs).
   (b) Baselines (unet, unetpp, attention_unet, transunet) -> SimpleTrainer
       (train.py:275-284; training/simple_trainer.py):
         * Loss = SimpleLoss = Dice + BCEWithLogits(pos_weight=2.0)
           (simple_trainer.py:34-39).
         * Early stopping on val Dice, patience = --patience (default 10;
           train.py:127-129, simple_trainer.py:71,80,282-343).
         * Optimizer/scheduler/AMP defined in simple_trainer.py (Dice+BCE path);
           GradScaler available in the generic Trainer class (trainer.py:633).
Checkpoint strategy:
   * MAFFNetTrainer: saves model_epoch_N.pth every epoch + best_maffnet.pth on
     best val Dice (trainer.py:517-529); copies best -> run_dir/model.pth
     (trainer.py:555-559).
   * SimpleTrainer: best checkpoint by val Dice; writes metrics.json
     (simple_trainer.py:331-337,409-411).
STATUS: Training pipeline reconstructed.  PASS.


3. EVALUATION PIPELINE
--------------------------------------------------------------------------------
Validation (per epoch):
   * MAFFNetTrainer._val_epoch (trainer.py:368-397): model.eval(); metrics computed
     on p1 (finest prediction, preds[0]); best model = highest val Dice.
   * SimpleTrainer: analogous val loop, monitors val Dice.
Test:
   * SimpleTrainer receives test_loader (train.py:230-235) and writes test metrics
     to run_dir/metrics.json (simple_trainer.py:409-411).
   * MAFFNetTrainer.train (used for MAFF-Net family) does NOT run the held-out test
     set by default; it writes VALIDATION metrics to run_dir/summary.csv
     (trainer.py:445-457,535). (MAFFNetTrainer.evaluate(test_loader) exists,
     trainer.py:571-603, but is not invoked from train.py for these models.)
   => Proposed/Restored/Faithful metrics are VALIDATION; baseline metrics are TEST.
Checkpoint selection: best validation Dice (both trainers).
Inference: model.eval() returns the finest-resolution prediction p1.
STATUS: Evaluation pipeline reconstructed.  PASS (with Major M2, val != test).

Aggregation: per-batch metrics weighted by batch size and averaged over the split

   * Aggregation utility utils/aggregate_benchmark.py scans experiments/*/metrics.json.

8. EXPERIMENTAL RISKS (repository-backed)
--------------------------------------------------------------------------------
CRITICAL: none (the pipeline is fully reconstructable from the repository).

MAJOR:
  M1. No training random seed / no determinism controls -> runs not bit-exactly
      reproducible (train.py, trainer.py, simple_trainer.py: no seed).
  M2. Proposed/Restored/Faithful report VALIDATION metrics (summary.csv) while
      baselines report TEST metrics (metrics.json) -> not directly comparable until
      a proposed test-set run is produced (trainer.py:445-457 vs
      simple_trainer.py:409-411).
  M3. Synopsis/paper baselines SGT-Net and Swin-UNet are not implemented in the
      repository; the implemented baseline set differs from the synopsis.

MINOR:
  m1. config.txt logs only 6 fields; seed/optimizer/scheduler/augmentation/hardware
      not recorded per run.
  m2. training_log.csv shared in save_dir (overwritten across runs); per-run epoch
      logs not preserved in experiments/.
  m3. MAFFNetTrainer has no early stopping (runs full epochs); only SimpleTrainer
      early-stops. (Behavioral difference between the two paths, not a defect.)

EDITORIAL:
  e1. Per-experiment hardware (GPU/CPU/driver) not recorded in the repository;
      only inferable from the live environment.
