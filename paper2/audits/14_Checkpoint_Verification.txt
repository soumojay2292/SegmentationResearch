3. FINDING (Major) — Paper-faithful runs used the PLACEHOLDER encoder
--------------------------------------------------------------------------------
The three Paper-faithful checkpoints strict-load into a model built with
sam_checkpoint=None, and their encoder keys are
   model.encoder.trunk.stem.weight / model.encoder.trunk.down.* ,
i.e. the shape-compatible _DummyHieraTrunk placeholder — not the real SAM2 Hiera
trunk (which would expose patch_embed/blocks keys and would fail a strict load into
the placeholder model).
=> The maffnet_original_ISIC*_final experiments were trained WITHOUT the pretrained
   SAM2 backbone.
Classification: Major (affects interpretation of the Paper-faithful results only).
Action: Document. This does NOT block test evaluation — the checkpoints load and can
   be evaluated as-is — but any reported Paper-faithful numbers must be labelled as
   obtained with the placeholder encoder, or the runs re-trained with real SAM2 if
   they are to represent a pretrained-backbone reproduction.
No other checkpoint is affected (Proposed and Restored use real SAM2).

                    VALIDATION metrics. It must NOT be overwritten; test metrics go
