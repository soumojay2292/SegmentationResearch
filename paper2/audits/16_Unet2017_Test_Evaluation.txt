            checkpoints/training_log.csv was untouched.

Deviation from the literal instruction, and why:
  (a) MAFFNetTrainer.evaluate() was NOT used. That method is deep-supervision
      specific — it indexes preds[0] on the model output, which is correct for the
      MAFF-Net 5-tuple but would index the batch dimension of U-Net's single logits
      tensor and produce wrong metrics. The identical metric function
      (compute_metrics) was applied directly to the U-Net logits instead, so the
      numbers remain directly comparable to every other run.
  (b) Output written to experiments/unet_final_2017/metrics.json rather than
      experiments/unet_ISIC_2017/metrics.json, because the latter directory does not
      exist and holds no run. Writing a metrics.json into an empty new directory
      would divorce the metrics from their checkpoint and summary. The chosen path
      is also picked up by utils/aggregate_benchmark.py, which scans
      experiments/*/metrics.json.
